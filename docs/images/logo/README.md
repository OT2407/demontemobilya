# Demonte Concept Logo Files

Drop logo files here to replace text automatically.

Supported filenames:
- `demonte-concept-light.svg` or `demonte-concept-light.png` for dark backgrounds (hero, navigation, footer)
- `demonte-concept-dark.svg` or `demonte-concept-dark.png` for light backgrounds
- Fallback generic: `demonte-concept-logo.svg` or `demonte-concept-logo.png`

You can use SVG or PNG. Transparent background is recommended.
